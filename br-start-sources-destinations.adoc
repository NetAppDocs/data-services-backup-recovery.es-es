Revisa los sistemas de origen, los sistemas secundarios y los destinos de almacenamiento de objetos que NetApp Backup and Recovery admite para las operaciones de backup y restauración en todas las cargas de trabajo.



[[supported-systems-for-backup-and-restore-operations]]
== Sistemas compatibles para operaciones de copia de seguridad y restauración

NetApp Backup and Recovery es compatible con sistemas ONTAP y proveedores de nube públicos y privados.



[[supported-regions]]
=== Regiones compatibles

NetApp Backup and Recovery es compatible con Cloud Volumes ONTAP en muchas regiones de Amazon Web Services, Microsoft Azure y Google Cloud.

https://bluexp.netapp.com/cloud-volumes-global-regions["Obtenga más información utilizando el Mapa de regiones globales"^]

[[supported-restore-destinations]]
=== Destinos de restauración admitidos

Puedes restaurar datos desde un archivo de backup, una máquina virtual, una base de datos o un recurso de Kubernetes que se encuentre en un sistema secundario (un volumen replicado) o en un almacén de objetos (un archivo de backup) en los siguientes sistemas. Las instantáneas residen en el sistema de origen y solo se pueden restaurar en ese mismo sistema.


NOTE: Wasabi es el único proveedor de almacenamiento de objetos compatible con S3 cualificado en este momento. No se han validado otros proveedores compatibles con S3.

Ten en cuenta las siguientes consideraciones relativas a la restauración:

* Las restauraciones desde Cloud Volumes ONTAP (replicación) solo se pueden realizar en Cloud Volumes ONTAP. Sin embargo, Cloud Volumes ONTAP en AWS también admite restaurar en Amazon FSx for NetApp ONTAP.
* Las restauraciones desde ONTAP local (replicación) solo se pueden hacer en ONTAP local.
* Las restauraciones desde Amazon FSx for NetApp ONTAP y Google Cloud NetApp Volumes originales (replicación) solo se pueden realizar en el sistema first-party correspondiente.
* La restauración desde Amazon S3 a Amazon FSx for NetApp ONTAP debe seguir este orden: Amazon S3 a Cloud Volumes ONTAP y luego Cloud Volumes ONTAP a Amazon FSx for NetApp ONTAP.



NOTE: Las referencias a «sistema ONTAP local» incluyen los sistemas FAS, AFF y ONTAP Select.
