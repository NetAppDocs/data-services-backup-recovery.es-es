= Limitaciones conocidas con NetApp Backup and Recovery for Oracle Database workloads
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Consulta las limitaciones actuales y las acciones no compatibles con las cargas de trabajo de Oracle Database en NetApp Backup and Recovery.

Las siguientes acciones no son compatibles con las cargas de trabajo de Oracle Database en la versión preliminar de NetApp Backup and Recovery:

* En la versión preliminar de Backup and Recovery para la implementación local de NetApp Console, las copias de seguridad en almacenamiento de objetos solo son compatibles con destinos ONTAP S3 y StorageGRID. El archivado de copias de seguridad no es compatible en esta versión preliminar.
* Copias de seguridad sin conexión
