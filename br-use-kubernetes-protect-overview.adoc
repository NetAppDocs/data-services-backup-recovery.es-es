= Flujo de trabajo de protección de Kubernetes con NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utiliza NetApp Backup and Recovery para descubrir, gestionar y proteger clústeres y aplicaciones de Kubernetes desde una única interfaz.

El siguiente diagrama muestra los componentes y la arquitectura básica para el backup y la recuperación de Kubernetes y cómo se pueden almacenar copias de tus datos en diferentes ubicaciones:

image:../media/backup-recovery-architecture-diagram.png["Diagrama de arquitectura de respaldo y recuperación para cargas de trabajo de Kubernetes"]

NetApp Backup and Recovery ofrece los siguientes beneficios para administrar cargas de trabajo de Kubernetes:

* Un único plano de control para proteger aplicaciones en múltiples clústeres de Kubernetes, incluidos contenedores y máquinas virtuales.
* La integración nativa con NetApp SnapMirror permite la descarga de almacenamiento para los flujos de trabajo de backup y recuperación.
* Copias de seguridad incrementales permanentes para aplicaciones de Kubernetes, lo que se traduce en objetivos de punto de recuperación (RPO) y objetivos de tiempo de recuperación (RTO) más bajos.
