= Acciones auditadas de NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utiliza esta referencia para ver qué acciones de NetApp Backup and Recovery registra NetApp Console en la página de auditoría. Para obtener detalles sobre cómo ver y filtrar eventos de auditoría, consulta  https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html#audit-user-activity-from-the-audit-page["Audita la actividad de los usuarios desde la página Auditoría"^] en la documentación de NetApp Console.

Para cada acción auditada, NetApp Console registra el nombre del servicio, el agente, el recurso, el usuario y el estado de la acción.

[cols="1,3"]
|===
| Categoría | Acciones 


| Restauración y recuperación  a| 
* Restaurar archivos desde una instantánea
* Restaurar volumen o archivos a partir de una copia de seguridad
* Revertir volumen a instantánea
* Inicia la exploración de archivos




| Operaciones de copia de seguridad y de instantáneas  a| 
* Crear copias de seguridad ad hoc en la nube
* Crear instantánea ad hoc
* Eliminar la política de snapshots de Azure NetApp Files
* Activar la copia de seguridad en un volumen
* Actualizar los metadatos de copia de seguridad del volumen (programado)




| Protección y replicación  a| 
* Inicializar la protección para el sistema
* Inicializar la protección de origen
* Inicializar la protección del objetivo
* Clústeres de iguales para la protección
* Iniciar la replicación de volúmenes




| Protección panorámica  a| 
* Activa la protección panorámica en un sistema
* Habilita la protección panorámica para los volúmenes
* Modificar la protección panorámica de los volúmenes
* Modificar la protección panorámica de un sistema




| Migración de copias de seguridad  a| 
* Migra copias de seguridad entre sistemas ONTAP
* Validar la migración de copias de seguridad




| Gestión de Cyber Vault  a| 
* Crear sistema Cyber Vault
* Eliminar el sistema Cyber Vault
* Desactivar el acceso a Cyber Vault
* Habilita el acceso a Cyber Vault




| Gestión del almacenamiento de objetos  a| 
* Crear bucket de almacenamiento de objetos
* Modificar el bucket de almacenamiento de objetos
* Modificar el almacenamiento de objetos para el sistema




| Gestión de credenciales en la nube  a| 
* Eliminar credenciales de la nube
* Registrar credenciales de nube
* Actualizar las credenciales de la nube




| Detección y configuración  a| 
* Descubre volúmenes y relaciones
* Actualizar la configuración de la aplicación


|===
