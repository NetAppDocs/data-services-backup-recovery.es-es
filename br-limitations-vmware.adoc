= Limitaciones conocidas para las cargas de trabajo de VMware en NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Consulta estas limitaciones antes de usar NetApp Backup and Recovery para cargas de trabajo de VMware.

NetApp Backup and Recovery no admite las siguientes acciones para las cargas de trabajo de VMware:

* En la versión preliminar de Backup and Recovery para la implementación local de NetApp Console, las copias de seguridad en almacenamiento de objetos solo son compatibles con destinos ONTAP S3 y StorageGRID. El archivado de copias de seguridad no es compatible en esta versión preliminar.
* Compatibilidad con vVol
* Integración de correo electrónico
* Compatibilidad con control de acceso basado en roles (RBAC)
