[[hyper-v-workloads-enhancements]]
=== Mejoras en las cargas de trabajo de Hyper-V

En esta versión, las cargas de trabajo Hyper-V introducen las siguientes mejoras:

* *Compatibilidad con NetApp MetroCluster*: NetApp Backup and Recovery ahora te permite proteger VM de Hyper-V replicadas por NetApp MetroCluster.
* *Protección de discos distribuidos para VM SAN*: en configuraciones CIFS y SAN, ahora puedes proteger todos los discos conectados a cada VM de un grupo de protección. Esto incluye tanto archivos distribuidos entre varios volúmenes ONTAP o sistemas de almacenamiento ONTAP (discos distribuidos) como archivos limitados a una sola ubicación.


Para más detalles sobre la protección de cargas de trabajo Hyper-V, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html["Aprende a proteger las cargas de trabajo de Hyper-V con NetApp Backup and Recovery"].



[[oracle-database-workloads-enhancement]]
=== Mejora de las cargas de trabajo de Oracle Database

En esta versión, Oracle Database workloads introduce la siguiente mejora:

*Gestión automática de registros de archivo*: durante las operaciones de restauración y clonación de bases de datos, NetApp Backup and Recovery detecta y monta automáticamente los registros de archivo necesarios y luego los desmonta una vez finalizada la operación. Se admiten fuentes de registros de almacenamiento primario, secundario y de objetos.

Para obtener detalles sobre cómo proteger las cargas de trabajo de Oracle Database, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-oracle-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Oracle Database con NetApp Backup and Recovery"].



[[microsoft-sql-server-workloads-enhancement]]
=== Mejora de las cargas de trabajo de Microsoft SQL Server

En esta versión, las cargas de trabajo de Microsoft SQL Server incorporan la siguiente mejora:

*Cambio en la política de licencias*: ya no se cobran cargos por las copias de seguridad que usan arquitecturas de disco a disco o de disco a disco con fan-out. Los cargos solo se aplican a las copias de seguridad en almacenamiento de objetos, incluidas las que usan arquitecturas 3-2-1 o de disco a almacenamiento de objetos.

Para obtener más información sobre cómo proteger las cargas de trabajo de Microsoft SQL Server, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-mssql-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Microsoft SQL Server con NetApp Backup and Recovery"].
