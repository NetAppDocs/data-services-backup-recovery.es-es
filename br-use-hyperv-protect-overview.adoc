= Protege las cargas de trabajo de Hyper-V con NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utiliza NetApp Backup and Recovery para hacer copias de seguridad y restaurar máquinas virtuales Hyper-V independientes, instancias de clúster de conmutación por error y máquinas virtuales aprovisionadas por SCVMM alojadas en un recurso compartido CIFS.

Puedes hacer backup de las cargas de trabajo de Hyper-V en Amazon S3 o StorageGRID y restaurarlas en un host de Hyper-V local.

Utiliza NetApp Backup and Recovery para implementar una estrategia de protección 3-2-1, con tres copias de tus datos de origen en dos sistemas de almacenamiento diferentes y una copia en la nube. Las ventajas del enfoque 3-2-1 incluyen:

* Múltiples copias de datos protegen contra amenazas cibernéticas internas y externas.
* Varios tipos de medios mantienen la viabilidad de la conmutación por error si uno de los tipos de medios falla física o lógicamente.
* La copia local te permite restaurar los datos rápidamente, y puedes usar las copias externas si la copia local se ve comprometida.


Cuando añades hosts de Hyper-V y detectas recursos, NetApp Backup and Recovery instala el plug-in de NetApp Hyper-V y el plug-in de NetApp SnapCenter Windows FileSystem en cada host de Hyper-V para ayudarte a gestionar y proteger las máquinas virtuales.
