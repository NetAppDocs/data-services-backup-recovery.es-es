NetApp Backup and Recovery es compatible con el nivel Archive de Google Cloud Storage para backups más antiguos. Infórmate sobre los costes de restauración y los tiempos de recuperación de los backups en este nivel.



[[supported-google-archival-storage-classes-for-netapp-backup-and-recovery]]
== Clases de almacenamiento de archivo de Google compatibles con NetApp Backup and Recovery

Cuando se crean los archivos de backup por primera vez, se almacenan en _Standard_ storage. Este nivel está optimizado para almacenar datos a los que se accede con poca frecuencia, pero sigue permitiendo un acceso inmediato.

Si tu clúster on-premises utiliza ONTAP 9.12.1 o posterior, puedes transferir backups más antiguos al almacenamiento de _Archive_ en la interfaz de usuario de NetApp Backup and Recovery tras un determinado número de días (normalmente más de 30 días) para optimizar aún más los costes. Los datos de este nivel tienen un mayor coste de recuperación, así que ten en cuenta con qué frecuencia podrías necesitar restaurar datos a partir de estos archivos de backup archivados. Consulta la sección de esta página sobre cómo restaurar datos desde el almacenamiento de archivado.

Cuando configures NetApp Backup and Recovery con este tipo de regla de ciclo de vida, no configures ninguna regla de ciclo de vida al configurar el bucket en tu cuenta de Google.

https://cloud.google.com/storage/docs/storage-classes["Obtenga más información sobre las clases de almacenamiento de Google"^].



[[restore-data-from-archival-storage]]
== Restaurar datos desde el almacenamiento de archivo

Almacenar archivos de backup antiguos en el almacenamiento Archive es mucho menos caro que en el almacenamiento Standard. Sin embargo, restaurar datos desde un archivo de backup en el almacenamiento Archive tarda un poco más y cuesta más.

¿Cuánto cuesta restaurar datos de Google Archive?:: Para conocer los precios detallados de Google Cloud Storage por región, visite https://cloud.google.com/storage/pricing["Página de precios de Google Cloud Storage"^] .
¿Cuánto tiempo tardará en restaurarse mis objetos archivados en Google Archive?:: El tiempo total de restauración consta de dos partes:
+
--
* *Tiempo de recuperación*: el tiempo necesario para recuperar el archivo de respaldo del archivo y colocarlo en el almacenamiento estándar.  A esto a veces se le llama el tiempo de “rehidratación”.  A diferencia de las soluciones de almacenamiento más "frías" que ofrecen otros proveedores de nube, sus datos son accesibles en cuestión de milisegundos.
* *Tiempo de restauración*: el tiempo que se tarda en restaurar los datos desde el archivo de copia de seguridad en el almacenamiento Standard. Este tiempo es el mismo que el de una restauración típica directamente desde el almacenamiento Standard cuando no utilizas un nivel de archivado.


--


[NOTE]
====
Restaurar un volumen o un archivo desde el almacenamiento de archivo puede tomar tiempo adicional. El trabajo permanece *In progress* en el Job Monitor mientras Backup and Recovery vuelve a intentar la restauración según la prioridad seleccionada. Supervisa la restauración en el *Job Monitor*; se completa cuando el trabajo alcanza un estado final, como *Completed* o *Failed*, después de todos los intentos de reintento. No inicies otra restauración a menos que el trabajo falle definitivamente.
