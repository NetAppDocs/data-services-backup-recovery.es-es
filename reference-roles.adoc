= NetApp roles de IAM para backup y recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Utiliza Identity and Access Management (IAM) para controlar a qué funciones y acciones de NetApp Backup and Recovery puede acceder cada usuario.

Para obtener más información sobre los roles de IAM específicos de NetApp Backup and Recovery, consulta https://docs.netapp.com/us-en/console-setup-admin/reference-iam-backup-rec-roles.html["Funciones de NetApp Backup and Recovery en la NetApp Console"^].
