= Administre el inventario de Microsoft SQL Server con NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Visualiza y gestiona los hosts, las instancias y las bases de datos de Microsoft SQL Server, y cambia o elimina su configuración de protección.

Puedes hacer lo siguiente para gestionar tu inventario:

* Administrar la información del host
+
** Suspender horarios
** Editar o eliminar hosts


* Gestiona la información de la instancia
+
** Asociar credenciales a un recurso
** Realice una copia de seguridad ahora iniciando una copia de seguridad a pedido
** Editar la configuración de protección


* Administrar la información de la base de datos
+
** Proteger bases de datos
** Restaurar bases de datos
** Editar la configuración de protección
** Realice una copia de seguridad ahora iniciando una copia de seguridad a pedido


* Configura el directorio de registros desde *Inventario* > *Hosts* antes de realizar una copia de seguridad de los registros de los hosts de la base de datos en instantáneas. Para obtener más información, consulta link:br-start-setup.html["Configurar los ajustes de NetApp Backup and Recovery"].




[[manage-host-information]]
== Administrar la información del host

Gestiona la información de los hosts para asegurarte de que los hosts correctos estén protegidos. Consulta, edita y elimina la información de los hosts según sea necesario.

*Rol requerido de NetApp Console*: Backup and Recovery super admin, Backup and Recovery backup admin, Backup and Recovery restore admin o Backup and Recovery clone admin. Si estás protegiendo datos almacenados en un clúster de Cloud Volumes ONTAP, también se requiere el rol de Cloud Volumes ONTAP Admin. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Obtenga información sobre los roles de acceso a la NetApp Console para todos los servicios"^].

* Configura el directorio de registros. Para más información, consulta link:br-start-setup.html["Configurar los ajustes de NetApp Backup and Recovery"].
* Suspender horarios
* Editar un host
* Eliminar un host




[[manage-hosts]]
=== Administrar hosts

Puedes gestionar los hosts detectados en tu sistema, de forma individual o como grupo.


TIP: Para gestionar un host, busca el estado «Sin gestionar» en la columna «Hosts». NetApp Backup and Recovery ya gestiona los hosts con el estado «Gestionado».

Después de administrar los hosts en NetApp Backup and Recovery, SnapCenter ya no administra los recursos en esos hosts.

*Rol requerido de NetApp Console*: superadministrador de Backup and Recovery o administrador de backup de Backup and Recovery. Si estás protegiendo datos almacenados en un clúster de Cloud Volumes ONTAP, también se requiere el rol de Cloud Volumes ONTAP Admin. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Obtenga información sobre los roles de acceso a la NetApp Console para todos los servicios"^].

.Pasos
. Desde el menú, seleccione *Inventario*.
. Seleccione una carga de trabajo para ver los detalles de protección.
. Seleccione el icono Accionesimage:../media/icon-action.png["Opción de acciones"] > *Ver detalles*.
. Seleccione la pestaña *Hosts*.
. Selecciona uno o varios hosts. Si seleccionas varios hosts, aparece la opción *Acciones masivas*. Selecciona *Gestionar (hasta 5 hosts)*.
. Seleccione el icono Accionesimage:../media/icon-action.png["Opción de acciones"] > *Administrar*.
. Revise las dependencias del host:
+
** Si no se muestra el vCenter, seleccione el ícono de lápiz para agregar o editar los detalles del vCenter.
** Si agrega un vCenter, también debe registrarlo seleccionando *Registrar vCenter*.


. Seleccione *Validar configuración* para probar su configuración.
. Seleccione *Administrar* para administrar el host.




[[suspend-schedules]]
=== Suspender horarios

Suspender programaciones para detener operaciones de respaldo y restauración durante el mantenimiento del host.

.Pasos
. En el menú de NetApp Backup and Recovery , seleccione *Inventario*.
. Seleccione el host en el que desea suspender las programaciones.
. Seleccione las *Acciones*image:icon-action.png["Icono de acciones"] icono y seleccione *Suspender horarios*.
. En el cuadro de diálogo de confirmación, seleccione *Suspender*.

[[protect-database-instances]]
=== Proteger instancias de bases de datos

Asigna una política a una instancia de base de datos para gobernar la programación y la retención de la protección de recursos.

.Pasos
. En el menú de NetApp Backup and Recovery , seleccione *Inventario*.
. Seleccione la carga de trabajo que desea ver y seleccione *Ver*.
. Seleccione la pestaña *Instancias*.
. Seleccione la instancia.
. Seleccione las *Acciones*image:icon-action.png["Icono de acciones"] icono y seleccione *Proteger*.
. Seleccione una política o cree una nueva.
+
Para obtener más información sobre cómo crear una política, consulta link:br-use-policies-create.html["Crear una política"].

. Proporciona los scripts que se deben ejecutar antes y después de la copia de seguridad.
+
** *Pre-script*: Introduce el nombre y la ubicación del archivo de script que se ejecutará automáticamente antes de que comience la acción de protección. Usa esto para realizar tareas o configuraciones adicionales antes del flujo de trabajo de protección.
** *Posdata*: Introduce el nombre y la ubicación del archivo de script que se ejecutará automáticamente una vez finalizada la acción de protección. Usa esto para realizar tareas o configuraciones adicionales después del flujo de trabajo de protección.


. Facilita la información de verificación para la instantánea:
+
** Ubicación de almacenamiento: selecciona dónde guardar la instantánea de verificación.
** Recurso de verificación: selecciona si quieres verificar el recurso en la instantánea local, en el almacenamiento secundario de ONTAP o en ambos.
** Calendario de verificación: selecciona la frecuencia: cada hora, cada día, cada semana, cada mes o cada año.
